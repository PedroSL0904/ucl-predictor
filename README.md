## 🔬 5. Ficha Técnica y Métricas del Sistema

Sistema entrenado con validación temporal **Walk-Forward Causal** sobre más de 1,990 partidos de UEFA Champions League (2011 a 2026):

- **Acierto de Signo (Sign Accuracy 1X2)**: **58.73%** (vs baseline de localía 50.5%)
- **Acierto en Doble Oportunidad (`1X`/`X2`)**: **74.34%**
- **Brier Score Calibrado**: **0.5406** (Baseline uniforme 0.6667)
- **Ranked Probability Score (RPS)**: **0.2032**
- **Arquitectura**: **Stacking Meta-Learner Layer 2 (OOF)** sobre Dixon-Coles Poisson + XGBoost + LightGBM + CatBoost.
- **Ingeniería de Features 2.0**: Distancia geográfica de viaje (Haversine km), fatiga, pedigrí histórico de club y coeficientes UEFA.
